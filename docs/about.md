# 关于 JinLingBlog

**JinLingBlog** 是一个持续生长的个人技术知识库。

它不追求堆积链接，而是希望把学习过程中的概念、实践与判断整理成可以再次使用的内容。

## Code

理解代码为何工作，也记录它在真实场景中何时不工作。示例会尽量保持简短、可运行，并解释背后的边界。

## Log

知识需要上下文。这里会保留问题背景、选择理由、失败尝试与最终结论，而不只是复制一个答案。

## Share

写作是一次公开的思考。文章会随着认知变化而更新，也欢迎通过 GitHub 和评论区补充不同观点。

## 技术架构

本站使用 VitePress 和 Markdown 构建，通过 Cloudflare Pages 发布，并使用浏览器本地索引完成全文搜索。核心页面是纯静态资源，不依赖数据库和长期运行的服务器。
