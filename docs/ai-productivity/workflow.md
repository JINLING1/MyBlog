# 可复用的 AI 协作工作流

稳定的 AI 产出很少来自某句神奇提示词，更多来自清晰的任务接口和可靠的验证闭环。

## 四个必要部分

| 部分 | 要回答的问题 |
| --- | --- |
| 目标 | 最终要交付什么，怎样算完成？ |
| 上下文 | 哪些事实、文件和既有约定会影响结果？ |
| 约束 | 哪些行为不能做，哪些格式必须遵守？ |
| 验证 | 如何用测试、数据或来源证明结果正确？ |

## 推荐流程

```text
描述结果 → 提供上下文 → 声明边界 → 生成方案
       → 小步实施 → 自动检查 → 人工复核
```

让 AI 先检查现状，再提出改动；把大型任务拆成可以独立验证的阶段；对于会变化或高风险的信息，要求引用可靠来源。

## 人的责任

AI 可以加速分析、草拟和重复劳动，但需求取舍、风险接受和最终发布仍需要人来负责。效率来自更短的反馈环，而不是取消验证。
