# 为什么建立自己的知识花园

收藏解决的是“以后可能会看”，知识花园解决的是“如何把看过的内容变成自己的判断”。

## 写下来才暴露空白

理解一个概念时，我们很容易用熟悉感代替掌握。尝试用自己的语言写出定义、例子和边界，会立刻暴露推理中跳过的部分。

## 文章不是终点

知识库里的文章可以不断更新。早期先记录当前最好的解释，遇到新案例后补充证据，发现原有结论不准确时保留修订痕迹。

## 连接比数量重要

真正有用的知识通常出现在概念之间：一个网络问题可能连接浏览器缓存、CDN 和部署策略；一个组件问题可能同时涉及状态建模和可访问性。

因此，衡量知识库的方式不应该只是文章数量，而应该看它是否帮助自己更快定位问题、形成判断并清楚地表达理由。
